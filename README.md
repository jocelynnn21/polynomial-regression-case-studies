# polynomial-regression-case-studies
This project explores the use of linear and polynomial regression models to understand and predict real-world engineering quantities from data. Two case studies are investigated:

- Predicting vehicle horsepower (HP) from fuel consumption–related features

- Predicting daily electricity consumption from weather variables

The goal is to evaluate how model complexity affects prediction accuracy and generalization, and to analyze underfitting and overfitting using quantitative metrics.
